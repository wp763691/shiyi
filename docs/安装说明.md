# 拾忆 · 安装说明（macOS Apple Silicon）

## 一、系统要求

- Apple Silicon Mac（M1 / M2 / M3 / M4 系列）
- macOS 12 或更高

## 二、依赖清单与安装命令

在「终端」中依次执行以下命令。可以逐条执行并等待完成。

### 1. 命令行工具（Xcode Command Line Tools）

```bash
xcode-select --install
```

如果提示已安装，可忽略。

### 2. Homebrew（Apple Silicon 的包管理器）

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

安装后按提示执行它输出的两行环境配置命令，使 `brew` 可用。

验证：

```bash
brew --version
```

### 3. Node.js（18+）

方式一（推荐）：Homebrew

```bash
brew install node
node --version
```

方式二（可选）：nvm 管理多版本

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
# 重开终端后
nvm install --lts
node --version
```

### 4. tmux（内置终端必需）

```bash
brew install tmux
tmux -V
```

### 5. Claude Code CLI

```bash
npm install -g @anthropic-ai/claude-code
claude --version
```

首次运行 `claude` 时按提示完成登录/模型接入（可继续使用你的 Anthropic 兼容端点，如 DeepSeek）。

### 6. Codex CLI

```bash
npm install -g @openai/codex
codex --version
```

首次运行 `codex` 时按提示配置模型与认证。

### 7. iTerm2（可选，但强烈建议：启用 iTerm 一键恢复）

```bash
brew install --cask iterm2
```

安装后：
1. 打开 iTerm2 → Settings（⌘,）→ **General → Magic**
2. 勾选 **Enable Python API**
3. 完全退出 iTerm（⌘Q）并重新打开一次

## 三、依赖速查表

| 依赖 | 用途 | 缺失影响 | 验证命令 |
|---|---|---|---|
| Node.js | 应用内置服务 | 应用无法启动 | `node --version` |
| tmux | 内置终端 / 新建会话 | 终端功能不可用 | `tmux -V` |
| Claude Code | Claude 会话 | 无法新建/恢复 Claude 会话 | `claude --version` |
| Codex CLI | Codex 会话 | 无法新建/恢复 Codex 会话 | `codex --version` |
| iTerm2 + Python API | iTerm 一键恢复 | 自动降级 Terminal.app | iTerm 设置内勾选 |

## 四、安装拾忆

## 安装步骤

1. 解压 `拾忆-macOS-arm64-v1.0.zip`
2. 把 `拾忆.app` 拖入「应用程序」
3. 首次打开若被系统拦截，在终端执行：

   ```bash
   xattr -dr com.apple.quarantine "/Applications/拾忆.app"
   ```

4. 打开拾忆即可。首次操作 iTerm / Terminal 时，按 macOS 提示授予自动化权限。

## 功能说明

- 会话：实时运行列表、历史检索、恢复会话（iTerm → Terminal → 复制命令三级降级）
- 技能 / 规则 / MCP / Agent / 命令 / Hooks：本地读取与管理，删除采用移入回收目录方式
- 内置终端：基于 tmux + 系统 Python PTY 桥，无需额外 Python 环境
- 配置文件编辑器：Claude settings.json / Codex config.toml，带语法高亮与自动备份

## 数据与隐私

- 所有数据均在本机（`~/.claude`、`~/.codex`、`~/.agents`）
- 服务只监听 `127.0.0.1`
- MCP 配置中的密钥不会在界面展示；配置文件编辑器内可见（请注意保密）

## 故障排查

- 打不开：先执行 xattr 命令；仍不行右键 → 打开
- 会话恢复只在 iTerm 新标签：确认已勾选 Enable Python API 并完全重启 iTerm
- 内置终端空白：确认已安装 tmux（`tmux ls` 可运行）
