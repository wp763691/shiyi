# ZYin（知音）产品需求文档

> 版本：v0.1（需求讨论稿）
> 日期：2026-08-03

本文为 ZYin（知音）产品方向的早期需求存档。当前仓库实现的是其衍生工具「拾忆」——面向 Claude Code / Codex 的本地会话与配置管理台。

## 一、产品概述

- **产品名称**：ZYin（中文名：知音）
- **产品定位**：个人 Mac 桌面应用，基于 Claude Code 内核，提供"多项目 + 导师/教练 + 语音电话式对话"的本地体验
- **核心价值**：像打电话一样，和一个越来越懂你的导师聊天
- **当前范围**：纯对话与分析，不做代码执行

## 二、目标用户与使用场景

- 个人用户，自己使用，单机无账号
- 每个项目配置一个专属"导师/教练"角色（如技术导师、写作教练、产品顾问）
- 通过语音或文字与角色对话，对话内容基于项目资料渐进式加载

## 三、核心功能需求

### 1. 项目管理

- 应用内新建、删除、重命名项目，每个项目对应一个本地文件夹
- 项目信息：名称、描述、角色设定、资料库位置
- 资料来源两种方式：
  - 手工放入 Markdown 文件
  - 通过语音或文字告诉工具自动创建（如"帮我建一个本周复盘模板"）

### 2. 角色与规则（CLAUDE.md）

- 每个项目有独立 CLAUDE.md，定义规则、角色、背景信息
- 提供角色模板库：技术导师、写作教练、产品顾问、英语陪练等，选择后自动生成 CLAUDE.md 骨架
- 主动性风格按项目配置：主动引导 / 被动答疑 / 混合（由用户选择）
- 支持可视化编辑 CLAUDE.md（分类：规则 / 角色 / 背景资料），无需手写 Markdown

### 3. 语音对话

- 常驻在线，类似打电话：检测到语音输入即开始分析和回复，无需按键
- 输入：本地语音识别（STT，如 whisper）
- 输出：回复朗读出来（TTS），同时界面流式显示文字
- 对话体验要求连续自然，低延迟优先

### 4. 渐进式资料加载

- 索引项目内 Markdown（≤500 个文件），本地向量库 + 全文检索
- 分层上下文模型：
  - 第 0 层（常驻）：CLAUDE.md 规则、角色设定、对话历史
  - 第 1 层（按需）：与当前话题相关的资料片段，检索后注入
  - 第 2 层（深读）：完整文档，仅在需要时加载
- 体验以"无感"为主：大部分时候看起来本来就懂项目
- 拿不准时偶尔向用户确认，不强行猜测

### 5. 长期记忆

- 跨会话记住用户的目标、进度、偏好，越聊越懂用户
- 每次对话后自动沉淀笔记，会话间用摘要衔接
- 全部本地存储

## 四、非功能需求

- 本地优先，无账号、无云同步
- 语音低延迟（识别本地化、回复流式）
- Mac 原生观感，后台常驻，可随时唤起
- 数据隐私：默认全本地存储（当前无额外隐私限制顾虑）

## 五、本期明确不做

- 多用户、账号体系、云同步
- 代码执行 / 文件修改（架构上预留，本期不做）
- 移动端、网页端

## 六、后续可细化项

- 语音打断机制（说话中途能否插话）
- 音色、语速偏好
- 环境噪音处理、音量自适应
- 索引更新策略（资料变化时何时重建）

## 七、技术方向（草案，待技术方案确认）

- 应用框架：Tauri 2（备选 Electron）
- 引擎接入：Claude Agent SDK（备选 `claude -p` 无头模式 + 会话续接）
- 语音识别：whisper.cpp 本地模型（备选 macOS Speech 框架）
- 语音合成：Apple AVSpeechSynthesizer / Piper
- 资料索引：sqlite-vec / LanceDB 本地向量库 + 全文检索
- 记忆存储：本地结构化笔记 + 会话摘要
